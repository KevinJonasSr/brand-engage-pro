Workflow

How changes land

Read this before pushing

Main is not protected, but this session used pull requests anyway so CI ran first. Keep doing that. Kevin authorized pushing, opening, and merging PRs in chat for this session only; get the go-ahead again each session. Never turn on auto-merge.

Before any destructive SQL, run select 1 from public.brands limit 1;. If it errors, you are in the Fan Engage database. Stop.

cd ~/Developer/brand-engage-pro && git checkout main && git pull
git checkout -b fix/short-description
# make the change, run tests in frontend/, commit with a conventional message
git push -u origin fix/short-description
gh pr create --base main --head fix/short-description --title "..." --body "..."
gh pr checks N --watch --fail-fast
gh pr merge N --merge --delete-branch
git checkout main && git pull

Database changes

  1. Confirm the ref is enfpviapxvqyoarwwsuf and run the brands check.
  2. Apply through the Supabase MCP first, then confirm with a select.
  3. Record it as 0066_short_name.sql, idempotent, with the "already applied to production" header line.
  4. Enum changes get their own migration file. Postgres cannot use a new enum value in the same transaction that adds it.
  5. Any new SECURITY DEFINER function starts closed: revoke from PUBLIC, anon, and authenticated, grant service_role, and grant a browser role back only with a written reason.

Conventions

House rules

  • Server code that moves point totals calls add_member_points (0061). Never read the total, add in code, and write it back.
  • New admin actions go through getAdminContext in lib/admin.ts. No new inline admin checks.
  • New cron routes need an entry in frontend/vercel.json and the crons table, behind verifyCronAuth.
  • Member-editable columns must be added to the allowlist in members_reject_integrity_column_updates(), the way 0058 added birthday_month.
  • Env var names only, never values: NEXT_PUBLIC_TURNSTILE_SITE_KEY, TURNSTILE_SECRET_KEY, NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY, STRIPE_SECRET_KEY, TWILIO_ACCOUNT_SID, TWILIO_AUTH_TOKEN, MAILCHIMP_API_KEY, MANDRILL_API_KEY, ANTHROPIC_API_KEY, OPENAI_API_KEY, CRON_SECRET.
  • Brand hero images are 1920 by 1080 with the focal point 32 percent from the top.
  • Jev runs in shadow mode for non-trivial work. Report its action and reason in one line, then use judgment.

Guardrails

Who can do what

  • SuperadminsKevin plus the standing group (Syncnatra, Hana, aiassistant, Carla Moore, Raymond Boyd) with community_id '*'.
  • Brand adminsScoped to one community_id. They see their members and nothing else.
  • Nellie's contentOffers and events go live only with Kevin's say-so. Press images from Charlotte Magazine and the Chicago Tribune need rights cleared before public use.
  • Member dataPhone numbers, emails, and birthday months stay in Supabase, Twilio, and Mailchimp. No exports.
  • Other productBrand Engage Pro is for businesses. Fan Engage Pro is for artist super fans. Never mix the two.
