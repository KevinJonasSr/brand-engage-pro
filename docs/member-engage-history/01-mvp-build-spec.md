# MVP Build Specification

## Goal
Build the first working version of the Supermember Platform that allows:
- members to join and engage
- members to earn rewards
- members to purchase offers
- brands to manage the experience

## Core Features

### Member Side
- onboarding wizard
- member dashboard
- rewards & tiers
- marketplace
- referrals

### Admin Side
- admin dashboard
- rewards manager
- marketplace manager
- basic analytics
